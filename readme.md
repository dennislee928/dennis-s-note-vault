MDR 市場（託管偵測與回應）
市場趨勢與市佔率
2025年全球MDR市場規模41.9億美元，年複合成長率21.95%，亞太地區成長速度最快。​

台灣本地代表：鼎新 Ai智管家、中華資安國際MDR、WiZON MDR。（委外MDR採購佔比超過40%且年增長，IT人力短缺為主要驅動力）​

典型營運：政府大機關、上市/中大型製造業、銀行與醫療，最低採購規模通常為10端點以上。

MITRE ATT&CK 支援／跨平台功能
台灣政府/大型企業近年訂購的 EDR 產品（如 Trend Micro Apex One、CrowdStrike、SentinelOne）普遍支援 Windows/macOS/Linux 並原生對應 MITRE ATT&CK 框架分析，可進行威脅鏈溯源。

MDR 託管方案多半與上述 EDR 模組做整合，提供全端事件通報。

小結：採購決策推薦與適用範例
